# 음성 문장 목록

> 정본 데이터는 `js/lines.js`다. 문장을 바꾸면 이 파일도 함께 고친다.
> 개발용 테스트 화면(`dev/test.html`)의 "LIST.md 대조"로 두 목록이 맞는지 확인한다.

## 녹음 규칙
- 파일 위치: `assets/audio/<파일명>` (하위 폴더 없음). 형식: mp3, 모노, 44.1kHz 권장.
- 파일이 없으면 같은 문장을 한국어 TTS로 읽으므로, **일부만 녹음해도 된다.**
- 여러 조각을 이어 쓰는 문장("사과가" + "세 개", "딸기" + "네 개" + "담아 줘!")은 **조각이 모두 있을 때만** mp3로 재생하고, 하나라도 없으면 문장 전체를 TTS로 읽는다. 조각은 한 묶음으로 같이 녹음한다.
- 말투: 밝고 다정하게, **천천히**(부모 설정 "음성 속도"는 TTS에만 적용된다). 앞뒤 무음은 0.1초 이하로 자른다.
- 부정 표현("틀렸어", "아니야")과 부정 효과음은 만들지 않는다.
